🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Access denied for user 'root'@'localhost'"
Solution: Password is RootPassword123! or check .env file

Problem: "Can't connect to MySQL server"
Solution: MySQL is running? Check Task Manager for mysqld.exe

Problem: "Database 'quizapp' doesn't exist"
Solution: Re-import schema:
  mysql -u root -pRootPassword123! < DB/quizappstructure.sql

Problem: "ModuleNotFoundError"
Solution: Activate venv: venv\Scripts\activate
         Then: pip install -r requirements.txt

Problem: Port 5000 already in use
Solution: Kill the process or change port in app.py
